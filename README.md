# 🐍 Python Crash Course, 3rd Edition: My Learning Path

This repository contains my solutions and documentation for the exercises in the book **"Python Crash Course, 3rd Edition"** by Eric Matthes.

## 💡 Why this Repo?

Unlike typical solution repositories, I am focusing on detailed learning documentation:

* **Solutions (`.py` files):** The working code for each exercise.
* **Explanations (`.md` files):** Detailed, Markdown-formatted breakdowns of the code, explaining the concepts used (e.g., variables, loops, classes) and any challenges encountered. This documents my actual learning process.
